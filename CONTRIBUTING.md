# Kontribusi
1. Baca `AGENTS.md`, `tasks/DECISIONS.md`. Aturan belum diputuskan? Buka issue, jangan menebak.
2. Fork → branch `feat/…` → PR ke `main`. Satu PR satu paket (WP).
3. Aktifkan hook: `git config core.hooksPath .githooks`. Jangan commit secret; jangan `--no-verify`.
4. Jangan ubah `design/`; usul perubahan lewat issue.
5. Wajib hijau: `cd backend && npm test && npm run typecheck`, `cd app && flutter analyze && flutter test`.
6. Izin ditegakkan di server. AI tidak mendiagnosis/memberi dosis.
Dengan berkontribusi, Anda setuju kontribusi dilisensikan sesuai `LICENSE`.
